# frontends

- `linux-kms/` — a Linux handheld (BananaOS today; ROCKNIX, muOS and others later): DRM/KMS on both panels, evdev,
  ALSA, the link scripts through `status.sh`, `host.sh`, `join.sh` and `down.sh`.
- `preview/` — on a computer: every screen as PNG files (`build/preview.sh`), also the README's tour.

What each system needs (launcher, scripts, paths, the radio) is in `platforms/`.
